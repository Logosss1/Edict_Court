## P0 盘点
- 起点：构建环境中**没有既有 Edict for Mac 代码**（无 AI_HANDOFF / README / docs 可读），因此本版本全部为**新建**；无需保留的未提交修改，未执行任何 reset / checkout / 批量删除。
- 调研：通读 Edict（README、`task.py` 状态机、`kanban_update.py`、`朝堂议政_开发规格.md`、各省部 SOUL、9 个旨库模板）、Yan-Agent（技术参考：权限链、上下文预算与压缩、长任务恢复、Git worktree、数据存放）、桌面 AI 编程工作台的常见布局（中央输入 / 智能体列表 / 检查面板 / 与 Editor 并存）、代码编辑器的常见功能面。
- 环境限制：npm / PyPI / Hugging Face 不可达，GitHub（git + release 资产）可达 → 依赖全部从 GitHub 获取并校验（见 THIRD_PARTY_NOTICES.md），Electron 二进制 SHA256 与官方 SHASUMS256.txt 一致。


## 什么是真实的 / 什么是 mock
- **真实**：运行时、状态机、编排、工具执行（真实读写文件、真实执行命令）、审计、持久化（SQLite）、三种协议的 HTTP+SSE 客户端、Electron 应用本身、Editor / 终端 / Git、git 工作树与命令快照（真实 git）、语言服务器与 ACP 套接字（真实子进程与套接字）、像素朝堂。
- **mock**：自动化测试中的 LLM 回复（`tests/mockLlm.ts`，脚本化，但使用真实线协议）。应用内**没有任何 mock 数据或假进度**——没配置模型时会明确提示去配置。
- **未验证**：真实模型下的效果（需 Key，脚本已备）；Mac 实机（安装、Gatekeeper、Retina、BSD `script` 终端 resize、`net.fetch` 代理）；真实的 ACP 编辑器与真实的 OAuth 授权服务器（自动化测试分别用协议级的模拟客户端和本机假授权服务器）。

## 已知限制
1. 终端不依赖原生模块：通过系统 `script` 获得 PTY，resize 通过 `stty -f <tty>` 下发；全屏 TUI 程序在极端 resize 下可能错位。
2. Monaco 为 0.40（GitHub 可获取的最新构建版）；内置语言服务覆盖 TS/JS/JSON/CSS/HTML。其它语言在本机装有对应语言服务器时显示它的诊断（跳转定义、引用、悬停目前只提供给官员的 `lsp` 工具），否则仅高亮。Edict 不替你安装语言服务器。不支持第三方编辑器扩展——扩展能力通过「技能（SKILL.md）」、MCP、LSP 与工具提供。
3. 类型检查（`npx tsc -p tsconfig.json --noEmit`，strict）覆盖 `src/` 下的主进程、渲染进程与共享代码；`tests/` 与 `e2e/` 由 tsx 直接运行，不做类型检查。
4. Linux 上生成的 DMG 内部是 ISO9660 + Rock Ridge（与 Bitcoin Core 的 macOS 发布流程相同），不是 HFS+/APFS；如遇挂载问题，使用同时交付的 zip，或在 Mac 上运行 `npm run package:mac`（改用 `hdiutil`）。
5. 签名为 ad-hoc，无公证；首次打开需在「隐私与安全性」中允许。
6. 仅 Apple Silicon；无自动更新（2.0.0 仍不包含）。
7. 正式美术尚未生成（见 P6）。
8. 思考档位的自动识别基于模型 id 的经验规则；中转站 / 私有模型请在「模型配置 → 思考程度」确认，或用「协议探测」实测。
9. MCP 实现了 tools、resources、prompts 与远程服务的 OAuth 登录（含 roots / ping 回应、日志与列表变更通知）；sampling / elicitation 未实现。
10. HTML 预览默认只允许本地资源（工作区与 localhost）；页面引用 CDN 时会提示并可由你临时放开。
11. 旨意工作树只在有提交的 git 仓库里、且是协同旨意时建立；Solo、不动文件的协同设计、非 git 文件夹仍在打开的工作区里执行，同一工作区的旨意依次执行。建工作树时主工作区未提交的改动不会带进去（会提示）。
12. 命令改动快照会把命令执行期间工作区里的所有改动都记到这条命令名下（包括你同时手动做的改动）；工作区超过 2 万个文件或快照仓库超过 512 MB 时，该工作区不再做快照。
13. 编辑器接入（ACP）：Edict 一次只有一个打开的工作区，编辑器的目录不同时须你同意切换；方案御览、御批等关卡要回到 Edict 处理；编辑器提供的 MCP 服务不会启动，图片和音频附件被忽略。
14. 命令沙箱只在 macOS 上生效（`sandbox-exec`，苹果已标为不推荐但仍可用）；其它系统上命令照旧直接执行。终端里你自己敲的命令不进沙箱。
15. 网页抓取只取页面文本，不执行页面脚本：要登录或靠脚本渲染的页面抓不到正文。「模型自带搜索」只在官方 Anthropic Messages / OpenAI Responses 接口上可用，中转站多半不支持（配置时会实测）。
16. 定时旨意只在 Edict 运行时按时下旨（关掉窗口不影响，退出就停），不装后台服务；错过的时间回来后最多补跑一次。到点的旨意若停在需要你批准的地方，会一直等你。
