# 安全、权限与数据

## 进程隔离
- 渲染进程开启 `sandbox`、`contextIsolation`，关闭 `nodeIntegration`，只能通过 preload 调用白名单 API（`src/main/api.ts`）。
- 页面由 `app://` 协议提供，不能越出 `dist/`；CSP 只允许同源脚本；禁止页面导航与新窗口，外链交给系统浏览器。
- 摄像头、定位等权限请求一律拒绝，只允许剪贴板写入与通知。

## 网络端口
Edict 不监听网络端口。唯一例外是远程 MCP 服务的 OAuth 登录：你点「登录」后，在 `127.0.0.1` 上临时开一个回调端口，只接受一次带正确 `state` 的 `/callback`，完成、取消或 5 分钟后关闭。编辑器接入（ACP）用的是本机 Unix 套接字；语言服务器和本地 MCP 程序经 stdio 通信。

## 权限模式
| 模式 | 读 | 写文件 | 命令 |
|---|---|---|---|
| 只读 | ✓ | ✗ | ✗ |
| 询问 | ✓ | 需批准 | 需批准 |
| 自动编辑（默认） | ✓ | 自动 | 安全命令自动，其它需批准 |
| 全自动 | ✓ | 自动 | 自动（高风险、发版 / 部署仍须确认） |

- **协同旨意的子任务**分只读 / 写入 / 验证：默认只读开工，写任务开工前单独确认，只读子任务要写时先弹升级卡。全自动模式不弹这两种卡。
- **允许规则**：普通风险的操作可选「本旨意内不再询问」或「本工作区永久允许」，按命令前缀、文件写入或 MCP 工具记录，可在「权限与审批」查看来源并撤销。
- **高风险操作任何模式下都须确认**，规则也不会放行：递归删除、`sudo`、丢弃修改的 git 操作、下载并执行远程脚本、网络外发命令、安装 / 卸载依赖、读取钥匙串、删除文件、读写 `.env*` / `*.pem` / `*.key` 等敏感文件、标为高风险的 MCP 工具。
- **发版与部署**（`git push`、publish、`gh release`、各类部署 CLI 等）每次都问，除非为该工作区开启「发版与部署永久允许」。
- **请旨**：只有全自动模式会在超时后按官员给的默认做法继续，其它模式一直等你。

## 路径边界与命令
- 文件工具拒绝工作区外路径和符号链接逃逸，禁止改写 `.git/` 内部；越界尝试写入审计。旨意有工作树时，边界就是工作树。
- 命令在工作区（或工作树）根目录执行，超时（默认 120 秒，最长 600 秒）后连同进程组终止，输出上限 64 KB。子进程环境剔除名称含 KEY / TOKEN / SECRET / PASSWORD / CREDENTIAL 的变量。

## 命令沙箱
macOS 上官员的 `run_command` 在 `sandbox-exec` 里执行：只能写工作区（或旨意工作树）、临时目录和包管理器缓存；`~/.ssh`、`~/.aws`、钥匙串、浏览器配置和 Edict 数据目录不能读；联网默认开，可关。被拦下时弹卡片：不用沙箱重跑一次 / 允许本工作区写该目录 / 作罢。沙箱不改变审批规则。

## 旨意工作树与命令快照
- 工作树建在数据目录下，结案前主工作区不改。Edict 只运行本地 git 命令，**不执行 fetch、pull、push**；仓库自己的 git hooks 会照常触发。合并有冲突时中止，主工作区保持原样，分支保留。
- 命令改动快照用 Edict 自己的影子 git 仓库，不碰工作区的 `.git`。`.gitignore` 忽略的文件、依赖目录和密钥文件不进快照。撤回时文件后来又被改过则整体不执行并列出冲突。

## HTML 预览
- 工作区和旨意工作树通过私有协议只读提供，不开端口；拒绝 `.git/`、`.env*` 和密钥文件。
- 预览页在独立会话分区里运行，去掉 preload、关闭 Node，不允许弹窗、下载和权限请求；外发网络默认拦截，需要 CDN 时由你临时放开。
- `preview_page` 的交互步骤以 JSON 数据传入固定脚本，不拼接成代码；最多 25 步、共 60 秒。

## 联网抓取与搜索
`web_fetch` 只抓公网 http(s)：解析域名后判断，回环、内网、链路本地地址一律拒绝，每一跳重定向都重查，最多 5 跳、单页 2 MB。`web_search` 走你配置的搜索服务或模型自带搜索，搜索服务的 Key 存在钥匙串。

## MCP
- `mcp.json` 中形似密钥的值保存时移入钥匙串，文件里只留占位符。
- 本地 MCP 命令首次运行或命令改变时须在原生对话框确认。
- 有副作用的工具需批准，高风险工具任何模式下都须确认，可按官员授权。审计只记参数名，不记参数值。
- OAuth 令牌只存在钥匙串，只以 `Authorization` 请求头发往签发它的服务；退出登录时删除并尽力吊销。
- 资源内容作为外部数据交给模型，注明其中的指令不必遵从。

## 语言服务（LSP）
Edict 不安装语言服务器，只查找本机已装的程序，按需启动、闲置 10 分钟停止。客户端只读：服务器发起的编辑一律拒绝。语言服务器是你自己安装的第三方程序，Edict 不限制它自身的访问。

## 编辑器接入（ACP）
默认关闭。开启后在数据目录下监听权限为 `0600` 的 Unix 套接字。每个编辑器首次连接须在原生对话框中批准（默认按钮是拒绝），批准只在本次运行有效。编辑器可以下旨、看进度、对待批操作准许或驳回；方案御览、御批等关卡和高风险操作默认只能在 Edict 里处理。

## 外部智能体（客卿）
客卿是你本机已装、支持 ACP 的编程智能体。Edict 只启动名册里的命令，不替你安装或登录；客卿只在旨意工作树里工作，经 ACP 发来的文件和终端请求走 Edict 的权限、审批与沙箱。**它用自带工具做的事不经过 Edict**：直接改的文件在办完后比对出来，记为客卿改动、可撤回；它自己的网络请求和费用由它自己决定。

## 定时旨意
定时旨意的权限在排定时设好：只读 / 每次改动都问 / 在旨意工作树里改（只在自己的工作树里免询问，高风险操作仍问）。合并仍由你决定。工作树准备脚本由你填写，以你的身份运行，不在沙箱里。

## 数据存放
数据在 `~/Library/Application Support/Edict/EdictData/`，本地存储不是安全沙箱：
- `edict.db`：任务、会话、奏折、设置、模型服务（不含 Key）与允许规则；`backups/` 是「立即备份」的副本，同样不加密。
- `secrets.json`：API Key、MCP 密钥与 OAuth 令牌，用 Electron `safeStorage`（钥匙串派生密钥）加密。
- `mcp.json`、`mcp-policy.json`、`lsp.json`、`acp-sessions.json`、`audit.jsonl`（哈希链审计）、`activity/`、`blobs/`、`skills/`、`designs/`、`snapshots/`、`worktrees/`。

能读取你用户目录的进程都能读这些文件（加密的 Key 除外）。

## 外发请求
只有你配置或主动触发的：模型服务、你添加的 RSS 地址、你粘贴的远程技能链接、你配置的 MCP 服务及其授权服务器、你放开后预览页引用的外部资源、`web_fetch` 抓取的网页与搜索服务，以及命令、语言服务器、本地 MCP 程序和客卿自身发起的请求。应用本身没有遥测、更新检查或预置的外部地址。API Key 只作为请求头发往对应服务，不写入日志、审计或测试夹具。
